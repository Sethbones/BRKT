## BRKT
so this is a thing, an off week of me experimenting with raylib's guide to make a breakout https://github.com/raysan5/raylib-intro-course
resulted in a me using to actually make a "semi-finished yet very unpolished" project with C 
raylib's quite fun, although it feels very much bloated in its chase for modularity, there's 5 ways to draw a texture, why?

### Features
 - 4 levels, all of which made in the span 30 minutes
 - a level system that takes images and uses color data to create the stage
 - 3 power ups, a paddle size increase, a paddle size decrease, and extra ball

 
### Requirements
#### Windows
w64devkit
ninja-build

### Basic Usage
if running it through the Zed Cod e Editor:
 - Press F4 go to Run and press "Update/Prepare Raylib"
 - After that's done
 - Press F4 go to Run and press "Prepare Desktop", select your settings, go to C and press F5 and do "Build and Run Desktop"
 - Enjoy.
if you just want to play:
 - A. there's a link in the about section to the Itch.io page for it
 - B. compile it yourself:
 - make prep
 - make
